class _FindFriendScreenState extends State<FindFriendScreen> {
  List<dynamic> currentProfiles = [];
  List<dynamic> matchedDogs = [];
  bool loading = true;
  bool showMatchedDogs = false;
  String? userEmail; // ✅ userEmail로 변경

  @override
  void initState() {
    super.initState();
    initUser();
  }

  Future<void> initUser() async {
    final prefs = await SharedPreferences.getInstance();
    userEmail = prefs.getString('userEmail'); // ✅ userEmail로 받기
    if (userEmail == null || userEmail!.isEmpty) {
      Navigator.pushReplacementNamed(context, '/login');
    } else {
      await fetchRandomUsers();
      await fetchMatchedDogs();
    }
  }

  Future<void> handleChat(String dogId) async {
    final response = await http.post(
      Uri.parse('http://localhost:8080/api/chat/create'),
      headers: {'Content-Type': 'application/json'},
      body: json.encode({
        'senderId': userEmail, // ✅ userEmail을 senderId로 사용
        'receiverId': dogId,
      }),
    );
    if (response.statusCode == 200) {
      final chatRoom = json.decode(response.body);
      Navigator.pushNamed(context, '/chat', arguments: chatRoom);
    }
  }
}

🧩 상황별 원인

  1. Android Emulator에서 그래픽 렌더링 설정이 호환 안 되는 경우

  2. x86 또는 ARM 가상 장치에서 OpenGL 가속 미지원

  3. Flutter 앱이 Image.network()나 Canvas/Skia를 통해 GPU 가속을 쓰려는 경우

  4. Windows/Linux에서 AVD가 GPU 가속 비활성 상태일 때

✅ 해결 방법 (상황별 대응)

✅ 방법 1: 에뮬레이터 설정 변경 (GPU 사용 활성화)

  1. Android Studio → AVD Manager 열기

  2. 에뮬레이터 옆 톱니바퀴(⚙️) → Edit

  3. Emulated Performance 항목의 Graphics → "Hardware"로 설정

  4. 저장 후 다시 실행

❗ 만약 이미 Hardware인데도 발생하면 "Software"로 바꿔서 시도해봐.

✅ 방법 2: 다른 에뮬레이터 사용 (x86_64 권장)

Flutter는 ARM보다 x86 기반 에뮬레이터에서 더 안정적으로 돌아감.

  • Pixel 4 API 33 x86_64

  • Graphics: Hardware or Software 둘 다 테스트

✅ 방법 3: 실제 기기에서 실행

OpenGL 문제가 있는 경우, 가장 확실한 해결은 실제 안드로이드 기기에서 디버깅하는 거야:

bash
flutter devices
flutter run

✅ 방법 4: Flutter 엔진 강제 설정 (비추지만 임시 해결)

AndroidManifest.xml에 다음 설정 추가해서 렌더링 엔진 변경 시도:

xml
<application
